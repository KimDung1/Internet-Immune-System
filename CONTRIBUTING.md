# 🤝 Contributing to Internet Immune System

First off, thank you for considering contributing to the **Internet Immune System**! It's open-source contributors like you that make digital protection accessible and trustworthy for everyone.

---

## ⚡ 30-Minute Quickstart Guide

1. **Fork & Clone the Repository**:
   `ash
   git clone https://github.com/KimDung1/Internet-Immune-System.git
   cd Internet-Immune-System
   `
2. **Install Dependencies**:
   `ash
   pnpm install
   `
3. **Environment Setup**:
   `ash
   cp .env.example .env.local
   `
4. **Run Local Dev Servers & Emulators**:
   `ash
   pnpm dev
   `
5. **Run Tests**:
   `ash
   pnpm test
   `

## 🌿 Branching & Commit Conventions

- **Branch Naming**:
  - eat/feature-name
  - ix/bug-name
  - docs/doc-update
  - security/patch-name

- **Commit Message Format (Conventional Commits)**:
  - eat(detect): add real-time URL risk score indicator
  - ix(extension): resolve storage sync issue in MV3 service worker
  - docs(readme): update repo link to KimDung1/Internet-Immune-System

## 📋 Pull Request Process

1. Ensure your code satisfies the **Definition of Done** in [docs/39_Sprint_Ceremonies/DefinitionOfDone.md](docs/39_Sprint_Ceremonies/DefinitionOfDone.md).
2. Create your PR against the main branch.
3. Fill out the PR template in .github/PULL_REQUEST_TEMPLATE.md.
4. Ensure all CI automated tests pass.
