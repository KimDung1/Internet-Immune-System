## ⚡ 30-Minute Developer Onboarding Flow

`
Step 1: Clone Repository                →  git clone https://github.com/KimDung1/Internet-Immune-System.git
Step 2: Setup Env (5 mins)              →  cd Internet-Immune-System && pnpm install && cp .env.example .env.local
Step 3: Run Local Emulators (10 mins)   →  pnpm dev:emulators (Firebase + Mock Gemini AI)
Step 4: Load Extension (5 mins)         →  Chrome -> Load Unpacked -> ./dist/extension
Step 5: Run Test Suite (5 mins)         →  pnpm test:unit && pnpm test:e2e
Step 6: Pick First Good Issue (5 mins)  →  Filter GitHub Issues by label: "good first issue"
`

## 🏛️ Executive Golden Rules

1. **Zero Unwritten Code**: No feature branch merged without corresponding PRD/UserStory mapping.
2. **Strict DoD**: PRs require 85%+ test coverage, passing prompt regression tests, and zero linter warnings.
3. **Prompt Version Control**: AI Prompts must be versioned with SemVer in 30_AI_Governance/.
4. **Security & Privacy First**: Zero clear-text PII logging allowed (compliant with Vietnam Cybersecurity Law 2018).
